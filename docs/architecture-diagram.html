Read it in 60 seconds
  • The member app (:3000) and admin app (:3001) are separate Next.js builds sharing @dhanvi/* packages; neither holds business logic.
  • Auth is one cookie session shared by both apps; the API enforces roles on every call.
  • Modules are folders in one process (Domain · Application · Infrastructure · Api); cross-module work joins one database transaction.
  • Money never moves without a provider record: Razorpay in, fake provider out (test mode only).
  • Hangfire, OpenTelemetry export and real email are wired but dormant.
