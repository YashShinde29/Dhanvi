# Random draws and reserved selection

RandomDraws now has Domain, Application, Infrastructure, and Api projects. It owns DHANVI_RANDOM_V1 canonicalization, unbiased deterministic mapping, secure entropy, immutable selection/snapshot models, policy, and verification. Groups supplies a transaction/persistence adapter; Cycles and memberships retain their own state transitions. See `docs/random-and-reserved-selection.md` for the exact immutable algorithm specification and commit/reveal limitations. No payout or auction execution is implemented.
